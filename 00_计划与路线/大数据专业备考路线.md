# 大数据专业备考路线（大一 · 目标：提升基础）
> 个人长期目标：本科打好基础，提升自身实力
> 身份：河北民族师范学院 数据科学与大数据技术 大一

## 一、核心目标时间线
### 大一（当前阶段）
✅ 课内：C语言、高数、线性代数稳住，保证期末高分，保住绩点、综测
✅ 课外：
- 吃透C语言基础，蓝桥杯省赛试水
- 跟着宋浩补线代，打好向量、矩阵底子
- 了解蓝桥杯、挑战杯、普通话大赛等综测竞赛
- 了解考公、选调生、大数据相关岗位方向

### 大二
- 专业课：Python、数据结构、数据库、概率论
- 竞赛：蓝桥杯、挑战杯，尽量拿奖项
- 开始英语持续背单词，准备四六级
- 确定方向：偏向AI算法 / 开发 / 考公

### 大三
- 开始系统看考研公共课+专业课
- 确定目标院校（211人工智能），查参考书目、真题
- 有机会进实验室做项目，丰富简历
- 期末稳住绩点，关注推免条件

### 大四
- 全力考研复习
- 同步备选：考公、事业单位、就业投递

## 二、需要持续补齐的能力清单
1. 编程：C → Python → 数据结构
2. 数学：高数、线代、概率论（AI考研重中之重）
3. 英语：四六级、考研英语
4. 项目/竞赛：用来综测、复试加分

## 三、风险与备选方案
主线：考研211人工智能
备选1：省内/周边选调生、公务员（大数据、计算机类岗位）
备选2：直接就业，后端、数据分析方向

## 四、当前短期计划（接下来1–2个月）
- 搞定C语言期末，把循环、分支、数组吃透，洛谷刷题
- 高数：极限、有界无界、导数重点吃透
- 线代：行列式、矩阵、初等行变换求逆
- 每周固定复盘，记录在 03_学习日志

## 五、复盘规则
每次阶段性考完、学完一个大模块，回来更新这份文档。
