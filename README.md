# 学习记录
2026级数据科学与大数据技术大一学生，目标冲刺211人工智能方向。
本仓库用来记录我的学习全过程，重点复盘踩坑、错题和理解思路，写给自己长期回看。

## 📂 目录说明
- 📌 **00_计划与路线**：长期目标、阶段规划、备考路线（考研、竞赛、综测）
- 💡 **01_灵感池**：竞赛选题、想法、临时思路、待调研清单
- 💻 **02_代码实践**：C语言、算法习题、蓝桥杯练习、可运行源码
- 📝 **03_学习日志**：每日复盘笔记，包含C语言、高数、线性代数错题与知识点
- 📚 **04_参考资料**：课件、汇总笔记、题库、学习资源链接

> 这不是项目作品集，核心记录三件事：学到哪里、卡在哪里、怎么把问题解决。
